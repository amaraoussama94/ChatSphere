# Contributing to ChatSphere

We welcome contributions from developers, designers, testers, and enthusiasts! Your input helps make ChatSphere better for everyone.

## Ways to Contribute

- **Report Bugs**: Help us identify and fix issues.
- **Suggest Features**: Share ideas for new functionalities.
- **Improve Documentation**: Enhance guides, tutorials, or help content.
- **Translate**: Assist in localizing the application.
- **Test**: Provide feedback on usability and performance.
- **Code Contributions**: Submit pull requests for enhancements or fixes.

## How to Get Started

1. **Explore the Project**: Familiarize yourself with the codebase and documentation.
2. **Check Issues**: Look for open issues on GitHub that match your skills.
3. **Fork and Branch**: Create a fork and work on a dedicated branch.
4. **Make Changes**: Implement your improvements or fixes.
5. **Test Thoroughly**: Ensure your changes work as expected.
6. **Fill PR Template**: When submitting a pull request, ensure the description follows the template and all required fields are completed.
7. **Submit a Pull Request**: Describe your changes clearly. The PR will be validated automatically.

## Pull Request Requirements

All pull requests must:
- Pass the automated PR Template Validation check
- Have a filled Description section
- Select at least one Type of Change
- Complete all Checklist items
- Include relevant tests and documentation updates

If validation fails, update your PR description accordingly.

## Guidelines

- **Be Respectful**: Follow our code of conduct in all interactions.
- **Document Changes**: Update relevant documentation for any modifications.
- **Quality First**: Prioritize stability, security, and user experience.
- **Communicate**: Discuss complex changes in issues before implementing.

## Reporting Issues

Use GitHub issues for:
- Bug reports (include steps to reproduce)
- Feature requests (describe the benefit)
- General questions or support

Provide as much detail as possible to help us assist you quickly.

## Community

Join our discussions on GitHub to connect with other contributors and stay updated on project developments.
